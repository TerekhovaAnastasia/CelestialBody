Абстрактный класс CelestialBody описывает небесное тело и имеет общие для всех наследников параметры:
имя (name), масса (mass, в M☉) - общий критерий сравнения, возраст (age, млрд лет) — универсальная характеристика,
расстояние от Земли (distance, св. лет).

Класс Star (звезда) дополнительно хранит радиус фотосферы в километрах (radius), 
светимость в единицах солнечной светимости L☉ (luminosity) и 
спектральный класс (spectralClass).

Класс Planet (планета) дополнительно хранит радиус твёрдой поверхности в километрах (radius), 
период обращения вокруг своей звезды в годах (orbitalPeriod) и 
признак наличия атмосферы (hasAtmosphere) - логическое значение true или false.

Класс BlackHole (черная дыра) дополнительно хранит безразмерный спин a* в диапазоне от 0 до 1 (spin) 
и безразмерный заряд Q (charge). у черной дыры нет собственного поля radius — понятие радиуса для неё 
не имеет смысла. Радиус Шварцшильда не хранится как отдельное поле, 
а вычисляется методом getSchwarzschildRadius() по формуле r_s = 2.95 * mass (км на каждую массу Солнца), 
поскольку он полностью определяется массой.
